# 📝 13. Tuyển Tập Toàn Văn Quyết Định Kiến Trúc (ADRs 001 - 010)

Tài liệu này tập hợp đầy đủ 10 quyết định kiến trúc đã được chấp thuận theo chuẩn **MADR (Markdown Architectural Decision Records)**:

* **ADR-001:** Chọn Flutter làm Framework Mobile độc quyền.
* **ADR-002:** Chọn NestJS làm Framework Backend Core.
* **ADR-003:** Chọn PostgreSQL 16 làm CSDL Quan Hệ Chính.
* **ADR-004:** Chọn MinIO làm Object Storage tương thích AWS S3.
* **ADR-005:** Áp dụng Mô hình Chapter Versioning Bất Biến (Immutable ChapterVersion).
* **ADR-006:** Phân tách Producer (NestJS BullMQ) và Consumer (Python Worker).
* **ADR-007:** Áp dụng WebSocket Reconnect Model cho tiến trình dịch AI.
* **ADR-008:** Trừu tượng hóa TranslationProvider qua Adapter Pattern.
* **ADR-009:** Sử dụng Dynamic HMAC-SHA256 Signed URLs bảo vệ ảnh Manga.
* **ADR-010:** Sử dụng Argon2id băm mật khẩu người dùng.
